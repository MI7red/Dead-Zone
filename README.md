# Мёртвая зона · NV-7 — HTML5

Готовая браузерная 2D-игра для ПК, Android и iPhone. Главный файл — **index.html**. Весь игровой код, стили и графика находятся в нём; внешние библиотеки, платные сервисы, аккаунты и сборка не нужны.

## Быстрая бесплатная публикация на GitHub Pages

1. Распакуйте ZIP на компьютере. Создайте на GitHub новый **публичный** репозиторий, например `dead-zone`.
2. Загрузите **содержимое** распакованной папки в корень репозитория. Рядом должны лежать `index.html`, `sw.js`, `manifest.webmanifest`, `icon.svg` и папка `icons`. Загружайте файлы, а не сам ZIP. Сохраните изменения в ветке `main`.
3. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку **main**, папку **/ (root)** и нажмите **Save**.
4. Дождитесь завершения публикации. GitHub покажет адрес вида `https://ИМЯ.github.io/dead-zone/`. Откройте его в браузере ПК, Chrome на Android или Safari на iPhone.

Файл `.nojekyll` уже включён в архив. Все адреса ресурсов относительные: игра работает и в репозитории-проекте, и в корне сайта. Домен покупать не нужно. GitHub Pages доступен бесплатно для публичных репозиториев: [официальная инструкция GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site), [настройка ветки публикации](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Управление на телефоне

- **Левый джойстик:** движение с плавным изменением скорости.
- **Правый джойстик:** направление прицела и атака при отклонении. Оба джойстика работают одновременно.
- **Собрать / E:** добыча, подбор, разговор, шкаф, кровать или верстак рядом.
- **Дверь / Зарядить:** открыть, закрыть или починить дверь; перезарядить оружие.
- **Еда / Вода:** быстро использовать подходящий запас.
- **Рюкзак:** еда, материалы, оружие, броня, навыки и остальные разделы.
- **База:** строительство. Выберите объект, коснитесь места в мире, при необходимости поверните и нажмите **Построить**. Для разборки включите соответствующий режим в меню базы, укажите свою постройку и удерживайте кнопку разборки.
- **Карта / Настройки / Пауза:** отдельные кнопки. Строка текущего задания открывает журнал.
- **Шесть ячеек оружия:** смена оружия касанием.

Поддерживаются вертикальная и горизонтальная ориентации. На небольшом телефоне горизонтальный экран даёт больше свободного пространства. Выбор управления находится в **Настройки → Управление**: автоматическое, сенсорное или клавиатура и мышь. На устройствах с мышью управление ПК остаётся доступным.

## Сохранение и перенос прогресса

Игра автоматически сохраняет прогресс в локальном хранилище браузера примерно каждые 8 секунд, после важных действий, при сворачивании и выходе. Сюжет и песочница имеют отдельные сохранения. Сохраняются база, мебель, шкафы, предметы, прочность, навыки, задания, решения, изготовление и таймер восстановления ресурсов. При закрытой игре производство и таймеры не идут.

В **Настройки → Сохранения на устройстве** есть ручное сохранение, **Экспорт JSON** и **Импорт JSON**. Экспортируйте JSON для резервной копии или переноса между компьютером, Android и iPhone. Импорт проверяет файл перед заменой сохранений.

Сохранения относятся к конкретному браузеру и адресу сайта. Локальный HTML-файл, опубликованный сайт и другой браузер могут иметь разные хранилища. Для переноса используйте экспорт и импорт. Прогресс и резервные копии не отправляются на сервер; ZIP содержит только игру, без личных сохранений.

## Офлайн и значок на главном экране

После первой успешной загрузки опубликованного HTTPS-сайта файлы игры сохраняются для офлайн-запуска. Не закрывайте первую загрузку сразу: регистрация офлайн-кэша должна завершиться.

- **Android:** откройте сайт в Chrome и используйте меню установки приложения или добавления на главный экран.
- **iPhone:** откройте сайт в Safari, затем **Поделиться → На экран «Домой»**.

Доступность установки зависит от браузера. Игра также работает в обычной вкладке. При обновлении сайта закройте все старые вкладки игры и откройте адрес снова: обновление не перезапускает текущую сессию посреди игры.

Офлайн-кэш работает через HTTPS или localhost. При обычном открытии HTML-файла игра работает без внешних ресурсов, но установка и service worker недоступны. Для проверки на ПК можно открыть `index.html` напрямую либо, если установлен Node.js, выполнить в папке `node serve.cjs` и перейти по показанному адресу. Для отдельной проверки в локальной сети есть `node serve.cjs --lan`.

## Сохранённые игровые возможности

- Сюжетный режим и песочница; финальная разработка лекарства NV-7.
- Большая карта, шесть биомов, день и ночь, пять видов заражённых.
- Разное оружие, случайная редкость, прочность, ремонт, броня и навыки.
- Еда, вода, медицина, добыча, выбрасывание и подбор предметов.
- Поэтапный крафт с компонентами, временем работы, требованиями к инженеру и верстаку.
- Строительство базы, двери, кровати, шкафы, хранение и точка возврата.
- Дерево и металл восстанавливаются каждые 30 минут активной игры; места базы и персонажей остаются свободными.
- Пять персонажей, расследование, спасение Милы и решения с последствиями.
- Русский, английский, узбекский, испанский, немецкий и турецкий языки.
- Все существующие текстуры, изображения предметов, освещение и два уровня качества графики.

## Файлы проекта

```text
index.html                 Полная игра: HTML, CSS и JavaScript
manifest.webmanifest       Параметры установки на главный экран
sw.js                      Офлайн-кэш, отдельный для папки этого сайта
icon.svg                   Значок для браузера
icons/                     PNG-значки Android и iPhone
.nojekyll                  Публикация обычных статических файлов
serve.cjs                  Необязательный локальный сервер без зависимостей
README.md                  Эта инструкция
```

Проект ориентирован на современные браузеры с Canvas 2D, Pointer Events и localStorage. Проверены игровые сценарии и интерфейс в настольном браузере и мобильных размерах экрана; проверка на физических Android и iPhone отдельно не проводилась. При необходимости снизьте качество в настройках — состав мира и игровые правила от этого не меняются.

Технические источники: [Pointer Events](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_events), [захват указателя](https://developer.mozilla.org/en-US/docs/Web/API/Element/setPointerCapture), [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).
